# 📊 Análise de Vendas com MySQL e Python

Este projeto demonstra a integração entre um banco de dados relacional (MySQL) e o Python para extração, análise de dados e geração de relatórios.

## 🧰 Tecnologias
- **MySQL Workbench:** Criação e gestão do banco de dados.
- **Python (Pandas & mysql-connector):** Processamento de dados e cálculos.
- **VS Code:** Editor de código.
- **GitHub Desktop:** Controle de versão.
